About Transaction Journal

Transaction Journal is a simple personal finance management application designed to help you record, organize, and review your daily transactions in one place.

🚀 How to Use

🧪 Demo Account

Want to try the application without creating an account? Use the Demo Login option on the login page. The demo account lets you explore the application's features and create, edit, and delete transactions for testing.

➕ Add a Transaction

  1. Open Add Transaction.
  2. Select Spent or Received.
  3. Enter the transaction details.
  4. Select a payment method: GPay, Paytm, BHIM, POP UPI, or Other.
  5. Optionally upload a receipt image.
  6. Add notes and transaction location if required.
  7. Click Save Transaction.

📂 View Transactions

Open the Transactions section to view your saved transactions. You can search using the transaction title, notes, or location.

🔎 Filter Transactions

Use the available filters to quickly find specific transactions:

  • Transaction Type: Spent or Received
  • Payment Method: GPay, Paytm, BHIM, POP UPI, or Other
  • Month: Select a specific month
  • Year: Select a specific year

✏️ Edit or Delete

  1. Open the Transactions section.
  2. Select the transaction you want to manage.
  3. Use Edit to update its details.
  4. Use Delete to permanently remove it.

📊 Dashboard

The Dashboard provides a quick overview of your transactions, including total transactions, total spending, total received amount, and payment method information.

👤 Profile

The Profile section displays your account information and membership details.

🔐 Your Data

Your transactions are associated with your account, so your records remain separate from other users' transactions.
