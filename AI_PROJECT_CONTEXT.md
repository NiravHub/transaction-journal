## Project Rules

- Follow MVC architecture.
- Keep code modular.
- Do not duplicate logic.
- Reuse existing functions whenever possible.
- Never break existing features.
- Preserve the current database schema unless instructed.
- Use async/await.
- Write clean, readable code with comments where appropriate.
- Handle all possible errors gracefully.

## Current Features

- User Authentication
- Add/Edit/Delete Transaction
- Image Upload
- Search Transactions
- Session Login

## Coding Standards

- Validate both frontend and backend.
- Return meaningful error messages.
- Avoid code duplication.
- Keep controllers small.
- Put reusable logic into separate modules.
